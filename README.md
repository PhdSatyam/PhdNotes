# Thesis Reading Room — Uncertainty, Credit and Climate (Complete Book)

Interactive study reader for all six phases (printed pp. 1–276, 42 chapters):
exact page images, extracted text, progress tracking, notes, bookmarks,
search (this phase or the whole book) and 457 self-check questions.

Static site, no build step. Progress is stored in your browser; use **Export /
Import** (top right) to back it up or move it between devices.

## Publish on GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`, then open
`https://<username>.github.io/<repo>/`. Free Pages needs a public repo.

## Lecture Notes and Reading plan
Version 4 adds the Lecture Notes as a second book (`data/ln/`, `img/ln/`) and a Reading plan tab that orders chapters from both books. Progress for each book is stored separately.


## Text edition (Read view)
Both books are also converted from their LaTeX source into clean web text (equations, tables, boxes, figures) under `data/ch*.js`, `data/ln/ch*.js` and `img/fig/`. In Read view you can highlight text in colours and add your own notes under any paragraph; they are saved with your reading progress and listed in the Notes and Saved tabs. The Page view (original PDF pages) remains available for checking equations and tables.
